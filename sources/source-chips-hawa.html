CHIPS HAWA (Nilesh Joshi, 21.03.2021)

CHIPS HAWA (Nilesh Joshi, 21.03.2021)

Original files: ../CHIPS HAWA.pdf (605 KB) + ../CHips and hawa.csv (4 KB, 63 rows)

Ingested: 2026-06-23

Summary (2 lines)

The definitive statement of NK's chips/hawa option-pricing model — gives the formulas and a rule-of-thumb strike-selection table indexed by VIX level and index. This is the reference point every other hedging source assumes you know.

Key takeaways

  • Three option types by moneyness:
  • OTM → only time value (hawa)
  • ATM & near ITM → time value + intrinsic value
  • Far ITM → mostly intrinsic value (chips)
  • Important nuance: chips/hawa definition uses spot price, but option behaviour follows the future price.
  • Formulas:
  • Call chips = Spot − Strike
  • Put chips = Strike − Spot
  • Hawa = Premium − Chips
  • Rule of thumb (fast chips calc): spot − nearest ATM, then subtract ATM−ITM gap from premium.
  • Half-hedge trade setup (the actionable rule):
VIX rangeIndexBuy (OTM, points away)Sell (OTM, points away)
18–22Bank Nifty+300+600
18–22Nifty+100+200
below 18Bank Nifty+200+400
below 18Nifty+50+100

(Stated as rule of thumb — adjustable to risk appetite.)

CSV data

CHips and hawa.csv is a worked calculation table for BN spot 17700 — strike prices with CE/PE LTPs and the resulting chips/hawa per strike (63 rows). Confirms the formula mechanics, no new rules.
