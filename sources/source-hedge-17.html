Source File

  • Hedge 17.pdf — By Mr. Nitish Kumar, NK Hedge School

Summary

Hedge 17 exploits Nifty-Bank Nifty correlation using monthly-weekly expiry combination. Both option buyer and seller, long and short, Nifty and Bank Nifty.

Key Points

What is Hedge 17?

  • Option sequence design using Nifty-Bank Nifty correlation
  • Correlation exists due to common stocks in both indexes
  • When Nifty up → Bank Nifty usually up
  • Sometimes Nifty halts but Bank Nifty keeps going

What's Unique

  • Uses merit/demerit of both monthly AND weekly expiry
  • You are: buyer AND seller, long AND short, monthly AND weekly, Nifty AND Bank Nifty
  • Covers all possible scenarios of Nifty/Bank Nifty index options

Execution

Step 1: Buy 1 lot Monthly Nifty (₹80-110 premium)

  • After 15th → next month expiry
  • 1st-10th → target ₹100-115

Step 2: Sell 2 lots Bank Nifty 1500-1700 OTM (weekly, ₹70-90)

  • Friday/Monday → current week; else next week
  • If price doubles intraday → exit 1 lot

Why "1700"?

  • Bank Nifty sold 1700 points OTM → hence "Hedge 1700" → "Hedge 17"

Bank Nifty Up 1700 Points Scenario

  • Nifty also up 350-400 minimum
  • ₹90 call → ₹350-400
  • Bank Nifty never gives loss until 1700 above strike
  • Weekly expiry → ₹90 → 0 → profit

Market Down Scenario

  • Nifty ₹90 → ₹60 possible
  • Bank Nifty sales → 0 on expiry → premium profit
  • When Nifty → ₹30, exit and re-enter next month @ ₹100-115

Returns

  • Positional: ₹1.5-1.6 lakh → 15-17% returns
  • VIX resistant — no impact from VIX volatility
  • Call side only
